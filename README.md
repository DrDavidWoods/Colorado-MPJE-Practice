# Colorado MPJE Mastery v5

120 practice questions; 78 questions substantively revised to reduce answer cues.

## Install on an existing GitHub Pages site
Extract this ZIP. Upload all app files to the same repository folder as the existing index.html, replacing the previous files. Keep the directory structure flat. Commit the changes, wait for Pages to deploy, then reopen online. Confirm the app displays **v5.0.0 • 120 questions loaded** before studying offline.

This package does not update an existing website automatically. Service-worker and asset versions were advanced together to refresh cached app content. Existing browser study history is retained; scores from earlier wording are not evidence of performance on the revised questions.

## What changed
See QUESTION_REVISION_NOTES.md. Authorities are available after a practice answer, not before. Exam feedback remains deferred to the end. Answer order remains randomized.

Original practice questions, not official or recalled NABP exam questions. This editorial revision is not a comprehensive new legal audit or psychometric validation.
